# One-sentence journey

This is a small program that writes one short text for make.fun's bounty `u-gudril-cool-one-sentence-one-journey-410686ca`, whose goal is a complete story about a journey told in exactly one sentence: main.py holds that sentence as a single string constant, asserts it is between 1 and 280 characters, and writes it as UTF-8 with no trailing newline to the folder named by `MAKEFUN_OUTPUT_DIR` when set, else `/output`, creating the folder if needed and printing the character count to stderr.

```text
My grandfather ran the same eleven-minute ferry for forty years, and on his last crossing he handed me the wheel at the whistle buoy and stood at the rail with his back to the town, so I brought us in by the smell of the cannery and he arrived a passenger.
```

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
